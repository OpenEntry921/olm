# OLM 자산

오름인터내셔널의 공식 브랜드 자산을 보관합니다. `logos/`에는 공식 로고·심볼(SVG 우선), `company/`에는 회사 소개 사진(WebP 우선, 필요 시 JPEG/PNG)을 둡니다.

파일명은 영문 소문자와 하이픈만 사용해 `brand-category-feature-size-view.ext` 형식을 따릅니다(예: `olm-logo-primary.svg`, `olm-company-office-large-front.webp`). 원본 PSD·AI·EPS와 웹에서 사용하지 않는 대용량 원본은 이 폴더에 넣지 않습니다.
