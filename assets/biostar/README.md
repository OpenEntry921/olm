# BIOstar 자산

BIOstar 공식 자산을 용도별로 보관합니다. `logos/`는 로고(SVG 우선), `hero/`는 대표 비주얼, `products/`는 제품 누끼(투명 배경 WebP 우선, PNG 지원), `ingredients/`는 성분 비주얼, `certifications/`는 확인된 인증 이미지용입니다.

파일명은 영문 소문자와 하이픈만 사용해 `brand-category-feature-size-view.ext` 형식을 따릅니다(예: `biostar-kitchen-foam-aloe-700ml-front.webp`). 원본 PSD·AI·EPS와 코드에서 사용하지 않는 대용량 파일은 포함하지 않습니다.
